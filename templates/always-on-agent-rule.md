# TypeScript quality rule for AGENTS.md / CLAUDE.md

Use `typescript-engineering-guardrails` for backend TypeScript changes. Inspect actual runtime (Node/Bun/Deno), dependencies, contracts and existing architecture. Prefer the least complex solution; no new controller/service/repository/interface factory chain without a concrete justification. Organize existing types, interfaces and constants in dedicated feature-local `types/`, `interfaces/` and `constants/` folders; share only real cross-feature contracts, do not invent declarations or folders. Validate untrusted data at boundaries, enforce resource/tenant authorization, bound async work, preserve migrations and operational contracts, test negative/security paths, show exact checks actually run. Do not refactor unrelated code or claim improvements without measurement. Audit mode must never modify the repository. Review independently for security, correctness and architectural slop.
